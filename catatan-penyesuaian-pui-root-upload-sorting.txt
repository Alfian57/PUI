Catatan penyesuaian pui.pdf untuk fitur upload root dan sorting HashBox

1. Konsep lokasi file perlu diperbarui.
   File tidak lagi wajib berada di dalam folder. Pengguna dapat menyimpan file langsung pada halaman utama "File Saya" atau di dalam folder tertentu.

2. Struktur basis data file perlu dijelaskan ulang.
   Tabel files perlu memiliki user_id sebagai pemilik file secara langsung, sedangkan directory_id menjadi opsional. Nilai directory_id kosong/null berarti file berada di root "File Saya".

3. Aturan upload perlu diperbarui.
   Upload file dapat dilakukan pada root "File Saya" tanpa memilih folder. Jika pengguna sedang membuka folder, file disimpan di folder tersebut.

4. Aturan duplikasi nama file perlu diperjelas.
   Nama file yang sama tidak boleh aktif pada lokasi yang sama. Lokasi yang dimaksud adalah root "File Saya" atau folder tertentu.

5. Tampilan daftar file perlu ditambahkan fitur pengurutan.
   Pengguna dapat mengurutkan isi "File Saya" berdasarkan terbaru, terlama, nama A-Z, nama Z-A, jenis item, dan item berbintang terlebih dahulu.

6. Breadcrumb perlu memperlihatkan root.
   Lokasi root ditampilkan sebagai "File Saya". Saat pengguna masuk ke folder, breadcrumb dimulai dari "File Saya" lalu dilanjutkan nama folder.
