Catatan penyesuaian pui.pdf untuk role Admin dan fitur Analitik HashBox

1. Perubahan aktor sistem
- Tambahkan aktor Admin.
- Aktor User tetap menjadi pengguna utama yang mengelola file dan folder pribadi.
- Admin hanya melakukan pemantauan analitik aplikasi secara agregat.
- Admin tidak dapat membuka, mengubah, menghapus, memulihkan, atau melihat struktur file/folder milik User.

2. Kebutuhan fungsional baru
- Admin dapat login ke aplikasi menggunakan akun dengan role admin.
- Admin dapat melihat dashboard analitik menyeluruh aplikasi.
- Admin dapat melihat jumlah pengguna, jumlah file/folder aktif, item sampah, item berbintang, ukuran penyimpanan aktif, dan ukuran data di sampah.
- Admin dapat melihat tren aktivitas agregat seperti login, upload, download, hapus, pulihkan, dan aksi berbintang.
- Admin dapat melihat komposisi tipe file, distribusi ukuran file, dan distribusi kedalaman folder secara agregat.
- Admin dapat memperbarui profile dan logout seperti user biasa.

3. Batasan privasi
- Dashboard admin tidak menampilkan nama file.
- Dashboard admin tidak menampilkan nama folder.
- Dashboard admin tidak menampilkan email atau nama pengguna.
- Dashboard admin tidak menyediakan tombol untuk membuka file/folder pengguna.
- Analitik hanya menggunakan data agregat dari metadata aplikasi.

4. Perubahan rancangan database
- Tabel users ditambahkan kolom role.
- Nilai role yang digunakan adalah user dan admin.
- Akun lama memiliki default role user.
- Akun admin development ditambahkan melalui seed.

5. Perubahan endpoint aplikasi
- Response login dan /api/v1/auth/me menambahkan field role.
- Tambahkan endpoint GET /api/v1/admin/analytics untuk mengambil analitik agregat.
- Endpoint file, folder, sampah, berbintang, dan riwayat user hanya dapat diakses oleh role user.
- Endpoint admin hanya dapat diakses oleh role admin.

6. Perubahan rancangan antarmuka
- Setelah login, user diarahkan ke dashboard file.
- Setelah login, admin diarahkan ke dashboard analitik.
- Sidebar admin hanya menampilkan menu Analitik.
- Topbar admin tidak memiliki pencarian file karena admin tidak boleh mengakses file pengguna.
- Halaman analitik menampilkan kartu ringkasan dan grafik agregat.

7. Penyesuaian diagram dan pembahasan
- Perbarui use case diagram dengan aktor Admin.
- Tambahkan use case: melihat analitik aplikasi.
- Perbarui activity diagram login agar route tujuan mengikuti role.
- Perbarui ERD dengan kolom users.role.
- Tambahkan pembahasan kontrol akses berbasis role dan batasan privasi admin.
