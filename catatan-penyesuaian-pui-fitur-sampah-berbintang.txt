Catatan penyesuaian pui.pdf untuk fitur Sampah dan Berbintang HashBox

1. Kebutuhan fungsional baru
- Pengguna dapat memberi bintang pada file dan folder penting.
- Pengguna dapat melihat daftar file dan folder berbintang pada menu Berbintang.
- Pengguna dapat menghapus file dan folder ke Sampah tanpa langsung menghapus permanen.
- Pengguna dapat melihat daftar file dan folder yang berada di Sampah.
- Pengguna dapat memulihkan file atau folder dari Sampah.
- Pengguna dapat menghapus permanen file atau folder dari Sampah.

2. Perubahan alur penggunaan
- Aksi hapus pada File Saya memindahkan item ke Sampah.
- Folder yang dipindahkan ke Sampah ikut memindahkan seluruh isi folder tersebut.
- Item yang berada di Sampah tidak tampil di File Saya dan Berbintang.
- Item berbintang tetap tampil di File Saya, dan juga muncul di menu Berbintang selama belum masuk Sampah.
- Hapus permanen hanya tersedia dari halaman Sampah dan membutuhkan konfirmasi pengguna.

3. Perubahan rancangan database
- Tabel directories ditambahkan kolom deleted_at untuk status Sampah.
- Tabel directories ditambahkan kolom starred_at untuk status Berbintang.
- Tabel files ditambahkan kolom starred_at untuk status Berbintang.
- Tabel files sudah memiliki deleted_at, sehingga kolom tersebut digunakan untuk status Sampah file.

4. Perubahan endpoint aplikasi
- GET /api/v1/trash untuk mengambil isi Sampah pengguna.
- GET /api/v1/starred untuk mengambil item Berbintang pengguna.
- POST /api/v1/directories/{id}/restore untuk memulihkan folder.
- DELETE /api/v1/directories/{id}/permanent untuk menghapus permanen folder.
- PUT /api/v1/directories/{id}/star untuk memberi bintang folder.
- DELETE /api/v1/directories/{id}/star untuk menghapus bintang folder.
- POST /api/v1/files/{id}/restore untuk memulihkan file.
- DELETE /api/v1/files/{id}/permanent untuk menghapus permanen file.
- PUT /api/v1/files/{id}/star untuk memberi bintang file.
- DELETE /api/v1/files/{id}/star untuk menghapus bintang file.

5. Perubahan UI/UX
- Sidebar pengguna menambahkan menu Berbintang dan Sampah.
- Card/list item file dan folder menampilkan aksi bintang dan pindah ke Sampah.
- Halaman Sampah menampilkan aksi Pulihkan dan Hapus permanen.
- Aksi kritis seperti hapus, hapus permanen, dan logout menggunakan dialog konfirmasi.

6. Penyesuaian dokumen skripsi
- Tambahkan fitur Sampah dan Berbintang pada bagian analisis kebutuhan sistem.
- Tambahkan use case baru: memberi bintang, menghapus bintang, memindahkan ke Sampah, memulihkan item, dan menghapus permanen.
- Perbarui activity diagram atau sequence diagram untuk proses hapus agar tidak langsung menghapus data.
- Perbarui ERD dengan kolom deleted_at/starred_at yang digunakan oleh files dan directories.
- Perbarui rancangan antarmuka dengan menu Berbintang dan Sampah pada dashboard pengguna.
