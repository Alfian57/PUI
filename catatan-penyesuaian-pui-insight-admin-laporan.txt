Catatan penyesuaian pui.pdf untuk fitur Insight, Analitik Admin lanjutan, dan Laporan HashBox

1. Penambahan fitur untuk User
- Tambahkan menu Insight pada dashboard user.
- Insight menampilkan ringkasan penyimpanan pribadi, jumlah file/folder aktif, jumlah item Sampah, item berbintang, ukuran penyimpanan aktif, ukuran Sampah, serta efisiensi deduplikasi.
- Insight menampilkan tren aktivitas pribadi seperti upload, download, hapus, pulihkan, dan aksi bintang pada rentang 7 hari, 30 hari, atau 90 hari.
- Insight menampilkan komposisi tipe file, file terbesar, dan item yang paling lama berada di Sampah.
- User dapat mengunduh laporan Insight dalam format PDF dan CSV.

2. Penambahan fitur untuk Admin
- Menu admin tidak hanya Analitik, tetapi dibagi menjadi Ikhtisar, Penyimpanan, Aktivitas, Kesehatan Sistem, dan Laporan.
- Ikhtisar menampilkan ringkasan penggunaan aplikasi secara agregat.
- Penyimpanan menampilkan kapasitas aktif, kapasitas Sampah, distribusi tipe file, distribusi ukuran file, total chunk, chunk baru, chunk yang digunakan ulang, dan rasio efisiensi deduplikasi secara agregat.
- Aktivitas menampilkan tren login, upload, download, hapus, pulihkan, dan aksi bintang secara agregat.
- Kesehatan Sistem menampilkan status API, database, vault-core, batas upload, rate limit, dan waktu pemeriksaan.
- Laporan memungkinkan admin mengunduh laporan analitik agregat dalam format PDF dan CSV.

3. Batasan privasi admin
- Admin tetap tidak dapat membuka, mengunduh, menghapus, memulihkan, atau melihat isi file/folder milik user.
- Laporan admin tidak menampilkan nama user, email user, nama file, nama folder, struktur folder, atau isi file.
- Semua data admin bersifat agregat dan hanya digunakan untuk pemantauan aplikasi.

4. Perubahan kebutuhan fungsional
- User dapat melihat Insight penyimpanan pribadi.
- User dapat mengunduh laporan Insight pribadi.
- Admin dapat melihat analitik berdasarkan kategori ikhtisar, penyimpanan, aktivitas, dan kesehatan sistem.
- Admin dapat mengunduh laporan analitik agregat.

5. Perubahan endpoint aplikasi
- Tambahkan GET /api/v1/insights untuk mengambil Insight user.
- Tambahkan GET /api/v1/reports/insight untuk mengunduh laporan Insight user dalam format PDF atau CSV.
- Tambahkan GET /api/v1/admin/system untuk mengambil status kesehatan sistem.
- Tambahkan GET /api/v1/admin/analytics/report untuk mengunduh laporan analitik admin dalam format PDF atau CSV.
- Endpoint admin hanya dapat diakses oleh role admin, sedangkan endpoint Insight user hanya dapat diakses oleh role user.

6. Perubahan rancangan antarmuka
- Sidebar user menambahkan menu Insight.
- Sidebar admin menampilkan menu Ikhtisar, Penyimpanan, Aktivitas, Kesehatan Sistem, dan Laporan.
- Halaman laporan menyediakan pilihan rentang waktu dan format file.

7. Penyesuaian dokumen skripsi
- BAB III bagian kebutuhan fungsional perlu menambahkan fitur Insight dan Laporan.
- Diagram use case perlu menambahkan use case melihat Insight, mengunduh laporan Insight, melihat kesehatan sistem, dan mengunduh laporan analitik admin.
- Pembahasan admin perlu diperluas dari satu dashboard analitik menjadi beberapa dashboard read-only.
- Bagian batasan privasi admin perlu menegaskan bahwa admin hanya melihat data agregat.
- Tidak perlu menambahkan tabel database baru karena fitur menggunakan metadata file, folder, chunk, dan activity log yang sudah ada.
